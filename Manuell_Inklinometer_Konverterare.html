CLINTON - Inclinometer splice: RST - Geosense - Soil

Load a reference survey and one or more current surveys (RST, Geosense or Soil raw export, either order) to compute and export mean deviation, absolute position, and displacement since baseline. - Ladda upp en nollmätning och en eller flera mätningar (RST, Geosense eller Soil rådatafiler) för att räkna fram och exportera medelavvikelse, abolutposition och utböjning mot nollmätningen.
REFERENCE / BASELINE

Reference survey

The reference survey to compare against — Nollmätningen att jämföra mot

CURRENT

Current survey(s)

One or more new readings to compare against the reference — e.g. every Geosense reading taken so far. Add files one at a time or select several at once; each survey inside a file (.dux files can hold many) is listed below so you can pick which ones to include. En eller flera nya mätningar att jämföra mot nollmätningar - t.ex. alla Geosense-mätningar som hittills gjorts. Lägg till filer en i taget eller markera flera på en gång; varje mätning i en fil (.dux-filer kan innehålla många) listas nedan så att du kan välja vilka du vill inkludera.

Already-computed displacement → AGD

For Soil Instruments / Gaudi exports that already contain cumulative displacement per depth per survey date (two sheets, axis A and axis B) — just pick the dates and it konverts it into AGD-format. Soil Instruments-/Gaudi-exporter som redan innehåller kumulativ förskjutning per djup per mätdatum (två excelblad, axel A och axel B) — välj bara datum och konvertera det till AGD-format.
SOIL / GAUDI EXPORT (.xlsx)

Pre-computed displacement file

Two sheets named "<point> A" and "<point> B", each with a depth column and one column per survey date. Pick one or more dates below to export together.
